1. Business Understanding：商業理解

本研究建立可解釋的洪水機率分數預測流程。輸入環境、人口與基礎設施相關數值，預測連續目標 FloodProbability；這是迴歸任務，不將目標二元化。假想使用情境為教學性的風險篩選與模型比較，成功條件是優於僅預測訓練平均值的基準，並能重現特徵選擇、評估與新樣本預測。

原始資料來源未提供可驗證的地點、時間、實體量測單位或事件觀測機制，因此不能直接投入真實防災決策。若未來要實際部署，應加入獨立地區／期間驗證與來源查證，而非用本資料的 R² 推論實務成效。

3. Data Preparation：資料準備

固定 random_state=42，先隨機切成訓練 30,000 列、驗證 10,000 列、測試 10,000 列。對每個候選模型，SimpleImputer(strategy="median") → StandardScaler → estimator 的參數只從訓練資料估計。資料沒有缺失值，補值步驟仍保留以支援未來輸入；不補目標值。完整切分列索引保存在 split_manifest.csv。

五種 selector 皆不接觸外層驗證／測試目標，先在訓練資料建立 14 特徵子集；一般模型的 alpha 和最終勝出組合由外層驗證 RMSE 決定。測試分數僅為最終描述性比較，不根據測試表格重新選勝出模型。資料沒有類別特徵，主實驗不做 one-hot；額外 CSV 實驗室對類別欄採訓練資料建立編碼。

沒有以全資料刪除離群值或依目標進行特徵工程，避免人為改善測試成績。新輸入超過訓練範圍時屬外插；網頁顯示提示，仍保留模型原始輸出。

4. Modeling：建模與特徵選擇

依 scikit-learn 線性模型文件，一般線性迴歸最小化平方殘差；Ridge 加入 L2 係數懲罰；Lasso 使用 L1 懲罰，可能產生零係數。兩種正則化方法都先標準化。alpha 的選擇範圍：Ridge = 0.01、0.1、1、10、100；Lasso = 10⁻⁶、10⁻⁵、10⁻⁴、10⁻³、10⁻²。

以完整 20 特徵作為基準，另比較五種 14 特徵子集。只有 20 個原始特徵，因此不勉強產生 25 或 30 特徵的版本。各 selector 的方法依據見 Feature selection，實作設定如下。

  • SelectKBest：以 f_regression 單變量 F 分數選出前 14 欄。
  • RFE：使用 Ridge(alpha=1) 逐步遞迴淘汰，保留 14 欄。
  • Sequential Feature Selection：backward SFS，在固定抽樣的 5,000 筆訓練列上做 3 折 CV，以負 RMSE 評分；每折內各自補值與標準化。採子樣本是計算成本取捨，結果不代表在全部訓練列上最優。
  • Lasso 排名：在標準化訓練資料上擬合 alpha=.001，再取絕對係數前 14 欄；這是 top-k 排名，不能聲稱 Lasso 恰好得到 14 個非零係數。
  • Permutation importance：僅將外層訓練集內部切為 75% 擬合／25% 排名，以 Ridge(alpha=1)、5 次打亂造成的 RMSE 變化選前 14 欄。外層驗證和測試不參與排名。此重要性是模型與資料相關的預測指標，不是因果效果。

實際值與預測值、殘差圖

最佳模型完整測試指標使用 10,000 筆；圖為固定最多 1,500 筆視覺抽樣。殘差 = 實際 − 預測。全特徵殘差只有浮點誤差，縱軸放大不代表實質預測誤差。

95% 預測區間：新觀測值的不確定性

為滿足題目「預測圖加上信賴區間或預測區間」要求，另外固定使用 SelectKBest14 / LinearRegression 產生 split conformal 預測區間，方法依據 Angelopoulos 與 Bates 的 conformal prediction 教程。其特徵選擇與模型只由訓練資料決定，此輔助模型不使用驗證目標挑選模型或 alpha；將 10,000 筆驗證列另作它的校準資料。以校準絕對殘差排序，取第 ceil((n_cal+1)×0.95) = 9501 小的值 q = 0.054611，對每筆測試預測建立 [ŷ−q, ŷ+q]。測試資料沒有用來調整區間寬度。

10,000 筆獨立測試的實際涵蓋率為 94.97%，平均區間寬度 0.109222。圖中顯示固定抽樣 80 筆測試觀測，依點預測排序，橘色帶為預測區間、綠點為實際值。這是新觀測值的預測區間，不是條件平均的信賴區間；名目邊際涵蓋性依賴校準與未來觀測的交換性，不保證每個輸入條件或真實地區的涵蓋率。完整 20 特徵模型區間會縮至浮點誤差，因此不把該退化區間當成真實預測確定性。

五項迴歸假設檢查

依 迴歸診斷文件的定義檢查線性、獨立性、等變異、殘差常態與共線性。主實驗使用 NumPy/SciPy 實作輔助迴歸和統計分布，沒有安裝 statsmodels；各檢定公式在程式中註明。完整 20 特徵 OLS 的前四項檢定因殘差接近零而退化，不解讀浮點誤差產生的 p-value；完整模型最大 VIF = 1.001002。

6. Deployment：預測與展示

模型包含訓練中位數、平均值、標準差、係數與截距，以 JSON 匯出；網頁直接使用同一組參數，無須安裝套件即可執行單筆預測。Python 批次預測指令：

python scripts/predict.py data/new_samples.csv --output results/predictions.csv

本模型的原始單位方程式約為 ŷ = 0 + 0.005×MonsoonIntensity + … + 0.005×PoliticalFactors。單個特徵增加 1，其餘固定時，模型輸出約增加 0.005；這是本資料的模型關係，不是現實中的因果結論。三筆新樣本輸入與預測保存在 data/new_samples.csv 和 results/new_predictions.csv。

互動頁提供模型選擇、六指標、散佈圖、殘差圖、特徵名單及新樣本輸入。互動分析採 單一分析區與資料集下拉選單，可選 Flood、50 Startups 或自選資料集；選自選資料集時顯示 CSV 檔案／網址匯入。網址需為公開 HTTP(S) CSV，且來源伺服器允許跨來源存取；讀取失敗可改用下載後的檔案。類別欄在訓練集建立 one-hot，省略首類避免虛擬變項共線性；未知或缺失類別回到基準編碼。瀏覽器端最多 50,000 列、39 個原始輸入與 100 個編碼欄位。

50 Startups 原始輸入只有 4 欄，僅作為題目允許的任意 CSV 匯入範例，不拿它充當符合 14–39 特徵條件的主資料。瀏覽器以固定 seed=42 重新分割 60/20/20；alpha 為使用者設定，沒有自動調參。瀏覽器實驗與正式 Python 結果獨立。
